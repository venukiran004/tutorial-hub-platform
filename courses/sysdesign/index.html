Systems, drawn before they are explained.

System design is a subject people reason about in boxes and arrows, so this course draws first and writes second. It starts with one request travelling through DNS, a load balancer and an app tier, then adds each piece a growing system needs — caches, replicas, shards, queues, circuit breakers — with the number that justifies it and the failure it introduces. Then the theory underneath: consistency, consensus, clocks and locks. Then design at every scale, from a class to a fleet of services; the operating numbers — tail latency, Little's Law, SLOs; security and the cloud; ML and LLM systems; how the large companies built theirs; and the interview, run as a method rather than a recital.

The progression

Five states, in order

Every module exists to move you from one of these states to the next. Most engineers can do the first two; interviews and incidents are decided by the last three.

01
I can name every box
The read path end to end — DNS, CDN, load balancer, app tier, cache, database — with a latency on every hop and the reason each box exists.
02
I can make it fast
Stateless scale-out, a caching strategy with its staleness stated, replicas with their lag, and a shard key that does not create a hot partition.
03
I can keep it correct
The consistency a feature needs, the isolation level that gives it, a queue consumer that is safe to run twice, and a slow dependency that cannot take the system down.
04
I can reason about the theory
Clocks that lie, Raft through a partition, the fencing token a lock needs, CRDTs that merge without asking — and design from a class up to a fleet of services.
05
I can defend a design
Capacity numbers, SLOs and the error budget, security and the cloud, ML and LLM systems, and a forty-five-minute interview run as a method.
Curriculum

The full path

Practice holds the production scenarios and the pattern programs. Interview holds the two-hundred-question bank, answers hidden until you ask. Modules marked soon are scheduled — the shape of the whole course is visible from day one.

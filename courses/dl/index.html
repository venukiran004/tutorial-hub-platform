The progression

Five states, in order

Every module exists to move you from one of these states to the next. The learn track takes you through them; the practice and interview tracks are where you find out whether it held.

01
I can derive the gradient
Backpropagation on paper for a two-layer network, the optimiser update rules written out, and a reason for every initialisation, normalisation and schedule.
02
I can build the architecture
A convolution and an LSTM cell in NumPy, matched against PyTorch and Keras; every landmark architecture's contribution named; attention written from scratch.
03
I can run the project
House prices with an ANN, sentiment with all four models, stock prices with three recurrent models, translation with a transformer — each run end to end.
04
I can work it by hand, and hear it
One forward pass, one backward step and one gate update carried through with numbers for each architecture; a waveform turned into features and decoded with CTC.
05
I can fix the run and pass the interview
A NaN with a cause you can name, a loss spike with a fix, and an answer for any of the two hundred questions in the bank that ends in a formula or a number.

Deep learning, built by hand and then trained.

The neuron, the gradient and the optimiser; the training loop as a discipline; the architectures for images, sequences and graphs; attention and the transformer as far as a deep-learning course should take them; the generative, self-supervised and reinforcement paradigms; audio; and compression and deployment. Every loss curve, gradient norm, latency and parameter count here was produced by running the code — NumPy from scratch, then PyTorch on a CPU — on data built so the failure exists: a ReLU that dies, a gradient that vanishes at depth thirty, a GAN that collapses to one mode.

The progression

Five states, in order

Every level exists to move you from one of these states to the next. If a lesson does not advance you along this line, it was cut.

01
I can derive the gradient
Backpropagation on paper for a two-layer network, checked against finite differences; you know why He initialisation works and what AdamW actually decouples.
02
I can make a run train
The loop is reproducible and resumable, a NaN has a cause you can name from the symptoms, and the overfit-one-batch test is the first thing you run.
03
I can build the architecture by hand
A convolution with im2col, an LSTM cell gate by gate, multi-head attention with its masks, a GCN layer from the normalised adjacency — in NumPy or plain tensors, matching the framework to six decimals.
04
I can pick the paradigm
VAE, GAN or diffusion; linear probe or fine-tune; DQN or PPO; GCN or GAT — each choice made from an experiment you ran, not a slogan.
05
I can ship it small and fast
Pruned and quantised with the accuracy cost measured, exported to ONNX with the latency timed, and an interview answer that ends in a number or a derivation.

The progression

Five states, in order

Every level exists to move you from one of these states to the next. If a lesson does not advance you along this line, it was cut.

01
I know the syntax
You can read Python and predict what it does — including the surprising parts.
02
I write clean Python
Your code reads as idiomatic because every idiom is a choice you can defend.
03
I build applications
Packaging, errors, tests, I/O — the machinery around the logic.
04
I understand trade-offs
Internals, performance and concurrency, so your decisions have evidence behind them.
05
I run it in production
Observable, deployable, debuggable at 3am by someone who is not you.

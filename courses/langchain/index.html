Composition, state, and what an agent breaks.

The reference notes, file by file and section by section: the Runnable protocol and what LCEL actually builds, retrieval taken from a baseline pipeline to BM25, rank fusion and cross-encoder reranking with every formula implemented from scratch, LangGraph's state machine with reducers, checkpoints and a human in the middle of a run, the agent patterns from router to swarm as the smallest graph that demonstrates each, context engineering as a budget, and the failure surfaces that only exist once an agent can act. The progression

Five states, in order

Every module exists to move you from one of these states to the next. The learn track takes you through them; the scenario and interview tracks are where you find out whether it held.

01
I can control a model
Every parameter on a request, what each does to the probability distribution, and the token arithmetic that tells you what the call will cost before you send it.
02
I can serve and adapt one
Prefill against decode, the KV cache and its memory, quantization and batching — then LoRA, where the update is low-rank and the settings each have a reason.
03
I can give it something to read
Chunking, embeddings and the index underneath; hybrid search and re-ranking; the advanced patterns; and RAGAS computed rather than imported.
04
I can say how it learnt to answer
Pretraining and Chinchilla, SFT and its loss mask, the Bradley-Terry reward model, PPO's KL leash, DPO derived to the line where the partition function cancels, then GRPO.
05
I can run it in front of users
Metrics computed by hand, traces that make a regression diagnosable, hallucination detected rather than hoped away, a bill that is under control, and guardrails that do not refuse everyone.

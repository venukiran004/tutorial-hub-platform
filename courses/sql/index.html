The progression

Five states, in order

Every level exists to move you from one of these states to the next. If a lesson does not advance you along this line, it was cut.

01
I can predict the rows
You know the order the engine evaluates and what NULL does at each step, so a count that comes back wrong is a surprise you can explain.
02
I can join and group without doubling
Every join is a multiplication you can size in advance; every aggregate collapses rows you can name. The LEFT JOIN stays outer.
03
I can answer it in one query
Windows, frames, CTEs and recursion replace the self-joins and the Python loop — top-n per group, running totals, hierarchies, sessions.
04
I can read the plan
EXPLAIN ANALYZE tells you which node is slow and why; you know which index would help and which predicate stops it being used.
05
I can keep it correct under load
You choose the isolation level by the anomaly it must prevent, write an upsert that survives a retry, and design a schema for the reads it will serve.

The progression

Five states, in order

Every level exists to move you from one of these states to the next. If a lesson does not advance you along this line, it was cut.

01
I know what the object is
An ndarray is a buffer plus strides, a DataFrame is columns on an index, and a view is not a copy — you can say which you hold.
02
I can get it in and reconcile it
CSV, JSON, Parquet and SQL arrive with explicit dtypes, validated joins and row counts that agree with the source.
03
I can say what is wrong with it
Duplicates, sentinel nulls, MNAR missingness and outliers each get a cause before they get a treatment.
04
I can build features that hold
Encodings, scales, transforms and windows that are computed from each row's past and fitted inside the fold.
05
I can defend the number
The split matches the deployment, the metric matches the base rate, and every leak has a check that would have caught it.
Curriculum

The full path

Three tracks, taken in any order or in parallel. Data Handling builds the ground in four phases, each depending on the one before it: the array and the frame you compute in, the ingestion and quality work that makes data trustworthy, the features a model actually sees, and the discipline — leakage, splits, pipelines, imbalance — that decides whether the score is real. Practice is two hundred programs to write from their titles and a thousand situations where the data decides the answer. Interview is four hundred questions on the array and the frame, with every answer folded away.
